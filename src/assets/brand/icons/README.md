# WORLD SMS SERVICE — Domain Icons

The official vector SVG icon library for WORLD SMS SERVICE is implemented as scalable, accessible, theme-reactive React SVG components in:
- `src/components/ui/AppIcon.tsx`
- `src/components/ui/icons/TelecomIcons.tsx`

All domain icons follow the standard 24x24 viewBox, stroke-width: 1.75, and currentColor inheritance rules.
